# Glow Home

Website for [Glow Home](https://www.glowhome.com.pk) — smart home automation and premium lighting solutions in Pakistan.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- GSAP

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```
